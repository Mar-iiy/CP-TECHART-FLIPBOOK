COZYSHOPS LITE - 10 FREE PROPS
A free sampler from CozyShops Vol.1 - Stylized Coffee Shop
by Sari3D
==================================================


WHAT'S INSIDE
-------------

  10 individual prop prefabs
      Side Table, Stool, Teapot, Espresso Cup & Saucer, Mug, Plate,
      Flower Vase, Potted Plant, Jar (Medium) and Cake Stand.

  A small demo scene
      A cozy seating-corner vignette showing the props arranged together.

Every prop is a standalone prefab. Nothing depends on the demo scene.

TECHNICAL
---------

  Render pipeline    Universal Render Pipeline (URP)
  Unity version      6000.0 LTS and up
  Textures           One 512x512 color atlas (shared with the full pack)
  Materials          Palette, Glass and Metal as used by these props
  Triangles          Low-poly - all props well under 1,000 triangles
  Colliders          Box collider on each prefab root
  Scale              1 unit = 1 meter, real-world proportions
  Scripts            None
  Rigging/animation  None - static props


NAMING
------

  SM_ / MD_ / LG_    mesh prefix by size class
  P_CozyShops_       prefabs
  M_CozyShops_       materials
  T_CozyShops_       textures


NOTES
-----

Transparent props read best when staggered.
  Glass items placed side by side tend to merge visually. Offset them in
  depth or alternate them with opaque props.

If props appear pink:
  The project is not using URP, or the materials need upgrading. Check that
  a URP asset is assigned under Project Settings > Graphics, or use
  Edit > Rendering > Materials > Convert Selected Built-in Materials to URP.
